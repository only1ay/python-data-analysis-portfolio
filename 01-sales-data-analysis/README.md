Retail Sales Data Analysis

Project Overview

This project focuses on analysing a sample retail sales dataset using Python. The aim is to understand the business’s sales performance, identify products generating the highest revenue and examine sales across different regions and months.

Project Objectives

The analysis aims to answer the following questions:

1. What is the total revenue generated?
2. Which product generates the highest revenue?
3. Which region records the highest sales?
4. How does revenue change from month to month?
5. Which products contribute most to overall revenue?

Dataset Description

The dataset is created for practice purposes and contains 12 sample sales records.

Column	Description
Date	Date of each transaction
Product	Product sold
Quantity	Number of units sold
Unit_Price	Price per unit
Region	Sales location
Revenue	Quantity multiplied by unit price

Tools and Technologies

* Python
* Pandas
* Matplotlib

Analysis Process

* Created and loaded the sample dataset.
* Converted transaction dates into datetime format.
* Calculated revenue for each transaction.
* Examined revenue by product and region.
* Grouped sales by month.
* Created a bar chart to compare product revenue.
